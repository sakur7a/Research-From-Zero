## 3. P0：先形成真实科研任务闭环

建议展示范围：选择 Layout 生成或图层生成中的一个细分问题，检索约 3 篇候选论文，追查训练实现、checkpoint、数据及评测条件，形成有来源的对比结果。不要首期同时覆盖全学科理论图谱。

- [ ] 确认正式赛题、参赛资格、提交入口、截止日期/时区和服务需保持可用的评审时段；为任务分配真实负责人。
- [ ] 项目所有者在本地设置真实模型 Key，并在提供商侧设可用的消费限制；不在聊天、代码或录屏中展示 Key。
- [ ] 选定一个实际支持工具调用的模型，记录服务协议、模型 ID、提示词版本和代码提交；不要把网络白名单当作兼容性验证。
- [ ] 通过「测试工具调用」，再分别测试已知论文+仓库、自主找资源、约 3 篇论文的小范围筛选。
- [ ] 固定 5–10 个真实小任务与人工核对表；数量为起步建议，不代表充分统计证明。覆盖部分发布、需申请、未找到、限流/网络失败和第三方实现等情况。
- [ ] 保存每次任务的来源、检查时间、错误、耗时和提供商返回的用量；与人工答案及同模型的普通检索/摘要方案对照。注明基线的数据/工具差异，不虚构公平性或提升百分比。
- [ ] 改进资源结构化结果：训练/推理/权重/数据/评测分开；归属、作者声明、访问状态、覆盖范围、版本匹配、验证深度各自记录。
- [ ] 打通从真实 agent 输出到资源对比表的流程；不能仅展示旧文献库表格而声称已自动生成字段级核验。
- [ ] 关键字段可展开查看来源与定位；允许人工修正并保留来源/修订记录，避免覆盖原始观察。
- [ ] 实测取消、超时、预算耗尽、工具错误、无结果和失效来源；保留已取得的证据，不以假结果填补失败。
- [ ] 审核演示用语：元数据可读不等于下载成功；文件名不等于可运行；有效证据 ID 不等于语义正确；未找到不等于资源不存在。

完成证据：至少一条真实可重复的小任务闭环及其导出、人工核对和失败记录，而非只通过模拟单元测试。

## 4. P0：在线 Web Demo 的上线前检查

### 推荐交付模式（尚未实现）

开发者本地版保留 BYOK。在线评审版使用项目方预配置且受限的模型服务，使评委不必提供自己的 Key；具体消费额度、部署平台和访问时段由所有者确认。可提供公开只读真实案例，以及按主办方允许方式发放的受控实时体验入口。

历史案例必须清楚标注「历史真实运行」、模型、检查日期和来源；合成数据标注「演示数据」。历史回放用于兜底，不能冒充当前实时运行，也不能代替全部可运行功能。

**禁止将当前无认证应用直接绑定公网，或仅加一个裸反向代理就发布。** 本节是待实现的验收要求，不是已提供的部署功能。

- [ ] 确认托管环境能访问所选模型与论文/资源 API；确认 HTTPS、持久化目录、备份及评审期可用性；不先作付费部署承诺。
- [ ] 增加在线演示配置，隐藏并在后端禁止普通访客修改/测试/清除全局模型配置；管理端单独授权。
- [ ] 对任务列表、详情、事件、导出、取消、恢复、文献和删除等所有入口做会话/账号级归属检查；仅首页加密码或隐藏按钮不算隔离。
- [ ] 提供隔离的临时体验库；不要使用开发者真实文献库和笔记。未经授权不能读取、终止或删除其他会话的任务。
- [x] 对外禁用本地模型端点与解析到内网的模型地址：`hosted` 模式直接拒绝 `127.0.0.1`/`[::1]` 与不全为公网的解析结果，且不给 `RE0_ALLOW_LOCAL_RESOLVER` 后门；自定义目标只能由部署者用 `RE0_LLM_ALLOWED_HOSTS` 加入（离线测试覆盖，真实部署待复验）。
- [ ] 请求频率限制、每账户任务配额、全站请求上限与"模型服务连续不可用"熔断已在 `quota.py` 实现并有离线测试（见 TESTING 的 `#13` 一节）；仍需在服务商侧设置可用的消费限制，并在真实部署上复验——在途请求仍可能计费，熔断只挡新任务。
- [ ] 并发方案已定为"单 worker + 明确的忙碌/队列归属 + 任务租约"（`busy`/`queue` 只说是不是你的槽，不说谁的）；仍需在真实负载下验证，且不能直接开启多个 worker 共写当前任务库。
- [ ] 模型/搜索/GitHub 密钥仅置于服务端受控配置；前端、异常、日志、导出和仓库均不暴露密钥，在线版不收集评委私人 Key。
- [ ] 部署侧的浏览器来源/Host/CSRF 配置经过验证；这些防护不能替代身份认证和对象权限。
- [ ] 首屏提供明确示例、能力边界和调用费用/材料发送说明；执行中能看到工具事件并停止。
- [ ] 准备经过审核的只读真实历史案例作为失败兜底，清楚标记不是本次实时结果；实时接口错误须如实显示。
- [ ] 说明体验数据留存期限及清除方式；原始日志和导出先脱敏，未经授权不公开访客研究主题。
- [ ] 从非开发机、无痕窗口及目标网络测试完整在线流程，检查外链、窄屏和错误状态；记录服务版本、时间与验收人。
